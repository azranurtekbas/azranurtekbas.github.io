# Azra Nur Tekbaş — Portfolio

**AI Engineer · Generative AI Creative**

🔗 **Live site:** [azranurtekbas.github.io](https://azranurtekbas.github.io/?lang=en)

Personal portfolio showcasing my work in Generative AI, from Turkish TTS, voice cloning and AI dubbing to AI-generated image and video advertising. The site is fully bilingual (English / Turkish).

## What's inside

- **Selected Works:** AI-generated ads produced with **Brandifier**, an ad-generation platform that turns a brand's website link into campaigns, slogans, images, videos, scripts and voiceovers. Each piece lists the model used (GPT Image 2, Nano Banana Pro, Seedream V5 Pro, FLUX.2 Pro and others).
- **Projects:** a detailed case study for each project:
  - **Brandifier:** AI advertisement generation pipeline
  - **AI-Powered Automatic Video Dubbing & Subtitle Generation:** my B.Sc. graduation thesis (WhisperX, DeepL, ElevenLabs voice cloning, Wav2Lip, FastAPI). The full thesis is available as a PDF on the project page.
  - **Emilia:** a TTS data pipeline (vocal separation, speaker diarization, WhisperX, DNSMOS filtering) used to build a Turkish speech dataset for fine-tuning
  - Film/TV Script Analysis Tool, IELTSGo, AAHaber
- **About, Skills & Contact**, with a downloadable CV

## Built with

Plain HTML, CSS and JavaScript, with no framework and no build step. All content lives in a single bilingual data file, and the site is hosted on GitHub Pages.

```
index.html        Home, works, projects, about, skills, contact
project.html      Case study page (project.html?p=<slug>)
css/style.css     Styles
js/content.js     All content (EN + TR)
js/common.js      Language switch, navigation, lightbox
js/home.js        Home page rendering
js/project.js     Case study rendering
assets/           Images, videos, CV and thesis PDF
```
